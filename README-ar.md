# مهامي اليومية — APK

## الطريقة السهلة (من غير ما تنزّل أي حاجة)
1. اعمل حساب على github.com (لو معندكش) وأنشئ Repository جديد (Private عادي).
2. ارفع محتويات المجلد ده كله (بما فيها مجلد `.github`) على الـ Repository.
   - لو مش شايف مجلد `.github` في الفايلات، فعّل "Show hidden files".
3. افتح تبويب **Actions** ← **Build APK** ← لو مش شغال اضغط **Run workflow**.
4. استنى حوالي 5 دقايق لحد ما يبقى فيه علامة ✔ خضرا.
5. افتح الـ run، ونزّل **مهامي-apk** من تحت (Artifacts). هتطلعلك ZIP، فكّه وجواه `app-debug.apk`.
6. ابعت الـ APK للتليفون وثبّته (لازم تسمح بـ "التثبيت من مصادر غير معروفة").

## الطريقة المحلية (Android Studio)
```
npm install
npx cap sync android
cd android && ./gradlew assembleDebug
```
الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`

## لو عدّلت في التطبيق
عدّل `www/index.html` وبعدين `npx cap sync android` وابني تاني (أو اعمل push وGitHub هيبني لوحده).

## الإشعارات في الخلفية
`TaskCheckWorker.java` بيشتغل كل ~15 دقيقة طالما فيه نت (والتطبيق مقفول)، بيقرا المهام من Firestore وبيبعت إشعار بالمهام اللي ماخلصتش.
- أول ما النت يرجع بعد انقطاع: إشعار فوري (تقريباً).
- لو النت فاضل شغال: تذكير كل 6 ساعات.
- لازم تدوس على 🔔 جوه التطبيق مرة واحدة وتوافق على الإشعارات.
